# !

Factorial: the product of every whole number up to this one.

| | |
|---|---|
| Syntax | `value!` |
| Group | probability |
| Runs on the PC | no |

## Examples

| Call | Result | Known from |
|---|---|---|
| `RETURN 5!;` | `120` | [emulator](../results.tsv) |

## Behaviour

**It is written after its argument, not before it.** `5!` answers 120
(emulator): five times four times three times two.

That is why HP's list gives this name no syntax string (HP help), just as it
gives none to `MOD`, which turned out to be an operator written between its
arguments rather than a function. A name on the list with no syntax is worth
treating as a sign that it is not called with parentheses at all.

Whether `!(5)` also compiles was not run (unverified). It was left out
deliberately: a call that fails to compile takes the whole batch with it, and
this one was already in a batch of two.

The factorial is what makes [COMB](COMB.md) and [PERM](PERM.md) work, and
those two were measured in the same phase: `PERM(5,2)` is 20, which is 5!
divided by 3! (emulator, and the arithmetic between the rows).

What it does with a negative or a fractional argument was not run
(unverified). A calculator may answer the gamma function for a fraction
rather than refusing.

It answers a plain real, type 0 (emulator),
[ppl.type-codes](../../topics/ppl.md#ppl.type-codes).

The interpreter does not implement it, so `hpprime run` cannot check a program
that uses it (unverified).
