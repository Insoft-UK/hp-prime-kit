## Behaviour

**The call is refused** (emulator), a plain error with no type.
[zoomin](zoomin.md) carries the account of the family: seven names, seven
refusals, and the reading that they change a view a batch does not have.

**Its name suggests it chooses a view to fit what is drawn** (HP help), which
would make it the one most dependent on there being something on screen --
and a batch draws nothing.

The interpreter does not implement it, so `hpprime run` cannot check a program
that uses it (unverified).
