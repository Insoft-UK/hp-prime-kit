## Behaviour

**The call is refused** (emulator), a plain error with no type, as for all
seven zoom commands. [zoomin](zoomin.md) carries the account of the family
and the probe that would settle it.

**It is the opposite of [zoomin](zoomin.md)** (HP help) and was refused in
exactly the same way, so nothing measured here separates the two.

HP's list gives the name no syntax string (HP help), like every name in this
family.

The interpreter does not implement it, so `hpprime run` cannot check a program
that uses it (unverified).
