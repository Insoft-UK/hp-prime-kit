# %

A percentage of a value.

| | |
|---|---|
| Syntax | `%(value, percent)` |
| Group | arithmetic |
| Runs on the PC | no |

## Examples

| Call | Result | Known from |
|---|---|---|
| `%(100,25)` | `25` | [emulator](../results.tsv) |

## Behaviour

**It is a function of two arguments, not a suffix.** `%(100,25)` answers 25
(emulator): twenty-five percent of a hundred. Writing `25%` the way a
spreadsheet would is not this command.

The order is value first, percentage second (emulator). Reversed,
`%(25,100)` would answer the same 25 here, which is exactly why one example
with two equal readings settles nothing and this one was chosen with
different numbers on each side.

HP's list gives this name no syntax string (HP help), so the shape above is
what the measured call shows rather than something published.

The interpreter does not implement it, so `hpprime run` cannot check a program
that uses it (unverified).
