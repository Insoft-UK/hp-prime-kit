## Behaviour

**It answers as HP's list spells it** (emulator), with GREEK SMALL LETTER PI,
U+03C0. That matters because its neighbour
[μ₀](μ₀.md) does not: the same list, the same app, the
same shape of name, and one of the two carries a codepoint the calculator
refuses. This row is what proves the refusal is about that name rather than
about Greek letters,
[ppl.mu-zero-spelling](../../topics/ppl.md#ppl.mu-zero-spelling).

**0.5 is a default, not a measurement** (emulator). The app ships with a
worked example loaded; a proportion of one half is the usual null hypothesis
for a test on a proportion, and nothing had been assigned when this was
read.

The interpreter does not implement it, so `hpprime run` cannot check a program
that uses it (unverified).
