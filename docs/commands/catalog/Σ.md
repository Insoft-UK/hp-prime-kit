# Σ

The sum of an expression over a range.

| | |
|---|---|
| Syntax | `Σ(expr, var, ivalue, fvalue)` |
| Group | catalog |
| Runs on the PC | no |

## Examples

| Call | Result | Known from |
|---|---|---|
| `EXPR("Σ(X,X,1,4)")` | `10` | [emulator](../results.tsv) |

## Behaviour

`Σ(X,X,1,4)` answers 10 (emulator), which is 1 plus 2 plus 3 plus 4: the
first argument is the expression, the second is the variable it runs over,
and the last two are the first and last values of that variable.

It answers a plain real, type 0 (emulator),
[ppl.type-codes](../../topics/ppl.md#ppl.type-codes).

**This is a different command from `ΣLIST`, and the name is one character**
(emulator). Both start with U+03A3, the mathematician's sum sign, but this
one sums an expression over a range while [ΣLIST](ΣLIST.md) adds up the
elements of a list it is handed. The third of the family,
[ΠLIST](../list/ΠLIST.md), multiplies instead and HP files it in another
group.

The variable can be one the calculator already has, as `X` is here
(emulator). Whether a name that holds a value is restored afterwards was not
measured (unverified), so a program that sums over `X` should not assume `X`
survives.

The interpreter cannot read the call at all (unverified): it fails inside
itself rather than refusing cleanly, so `hpprime run` cannot check a program
that uses it.
