# Plan 02: the checks the list decided on

The user approved the list and its nine checks on 2026-09-25, and confirmed
that `Check` was pressed on `ZQMU1` and `ZQEP`, so both refusals of 10-01
stand.

## The checks

| Rule | Fact | Level | Flags |
|---|---|---|---|
| `mu-zero` | `ppl.mu-zero-spelling` | error, emulator | `μ₀` with the Greek mu in code, not in a string |
| `getkey-code` | `interface.getkey-position`, `interface.key-codes` | warning, G2 | a variable assigned from `GETKEY`, compared in the same function with text, or with a number that is not a whole number from -1 to 50 |
| `string-index` | `ppl.string-index-code` | warning, emulator | a variable that only ever holds text, indexed and compared with text |
| `draw-units` | `interface.draw-units` | warning, emulator | a drawing command without `_P` with a literal coordinate beyond 16 units, or a `DIMGROB` size beyond 32: pixels written in units |
| `draw-then-return` | `interface.draw-then-return` | warning, G2 | an exported function that draws, itself or through the file's own functions, and nowhere waits |
| `wait-undrained` | `interface.drain-then-wait` | warning, G2 | a loop waiting for `GETKEY` with no loop draining it earlier in the function |
| `expr-in-loop` | `ppl.expr-dynamic-access` | warning, G2 | `EXPR` inside a `FOR`, `WHILE` or `REPEAT` |
| `export-clash` | `ppl.global-namespace` | warning, emulator | an exported name on HP's list, CAS names aside: it hides the calculator's own |
| `build`: `MOUSE` | `interface.mouse-lists` | warning | a Python call whose PPL string is `MOUSE` itself, with nothing flattening it |

**What a rule cannot see it leaves alone.** A function that calls a name
defined in no file in view is not judged by `draw-then-return`; an app's
hooks are not either, since the app, not Home, is what they return to.
Numbers that are not literals are not judged by `draw-units`.

## What holds each

A case it catches and one it stays quiet on, in `EVIDENCE` or `MULTI` in
`tests/test_lint.py`, and the `build` check in `tests/test_appdir.py`.
Every line of `CAUGHT` that said "to write" names its rule or its test, and
`caught_list` then fails on a "to write" left over. The kit's own PPL --
`examples/`, `templates/`, the guided path -- is linted with the new rules,
and what they say there is either fixed in the example or narrows the rule.

`docs/tools.md` describes each rule where the others are, and
`ppl.mu-zero-spelling` stops saying the linter flags neither spelling.
