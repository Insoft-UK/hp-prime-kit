<context>
@.planning/phases/08.1-home-and-system-variables/08.1-CONTEXT.md (decision 3)

**The tool**, built and tested before the session: `--compile FILE` reads
programs headed `[fact] NAME`, puts them on `Prime_1` with `HPKDOC` and the
controls `ZCOK` and `ZCBAD`, prints the order to press `Check` in, and after
the window closes reads each file for a compiled block. If `ZCOK` has none or
`ZCBAD` has one, nothing is concluded. Twelve tests with a stand-in emulator.
While writing the probe file, the reader was found to attach the file's own
`#` comments to the program before them, which would have made that program
fail for a reason that is not the question; a comment line now belongs to no
program, and a test holds it.

**The session**: 22 programs, one question each, in the order compilation
needs (`ZQLST` before the program that calls it); then `HPKDOC`, which runs
each zero-argument program as `EXPR("NAME")`, asks Home for `AREA(2)` with a
program exporting `AREA`, and times `WAIT(-1)` twice with `TICKS` -- straight
after the Enter that started it, and after draining the keyboard. Those two
rows wait for a key if `WAIT(-1)` waits.

**By hand**: the line `Check` names for `ZQTWO`, whose bad lines are 4 and
12, is read off the screen by the user.
</context>
