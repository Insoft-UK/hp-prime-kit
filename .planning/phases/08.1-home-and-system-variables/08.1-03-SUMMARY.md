# Plan 03 summary: the plot view, and the app's mode settled

## What was run

One batch of 69 calls on the Virtual Calculator 2.4, build 2025-09-15, on
2026-09-24, with the Function app active, waiting three hours through the
harness's own `timeout`. All 69 read back.

## What was built

- **30 entries** in `common-plot-view`: the window, its marks and zoom, the
  seven switches, the parameter, polar and sequence ranges, and the
  background picture. **With them every one of the 65 variables of Home and
  the system has an entry, and CMD-12 is complete.**
- **A fact renamed and widened before it was published**:
  `apps.app-angle-overrides-home` became
  [apps.app-mode-overrides-home](../../../docs/topics/apps.md#apps.app-mode-overrides-home),
  since the complex setting and the number format behave as the angle does.
- **`interface.draw-units` says the units follow the window**, where it had
  said that was not measured.
- **`AAngle`, `AComplex`, `ADigits`, `AFormat`, `NumZoom`, `HAngle`,
  `HComplex` and `HFormat`** carry the new rows. The three app-mode entries
  that 08.1-02 left saying "that does not show it is ignored" now say what it
  does.
- **The README test** now asks for "all 65 variables" once they are all
  written, and for "the other N" only while some are not.

## What the rows said

- **The app's values are shifted by one against Home's, as 08.1-02 guessed.**
  `AComplex` at 2 made `(-4)^0.5` answer `2*i` with `HComplex` at 0;
  `AFormat` at 2 made `STRING(1/3)` answer `"0.3333"`, four places from
  `ADigits`, and with both at 2, `"0.33"`. 0 leaves the choice to Home, 1 is
  the first of the app's own choices.
- **A drawing coordinate follows the plot window.** `C→PX(0,0)` is
  `{160,109}` with the reset window, `{1,109}` with `Xmin` at 0 and
  `{160,0}` with `Ymax` at 0. The window is −15.9 to 15.9 by −10.9 to 10.9.
- **The parameter, polar and sequence ranges refuse while the Function app
  is active**, read and set alike: `Tmin`, `Tmax`, `Tstep`, the three `θ`
  names, `Nmin`, `Nmax`.
- **`HAngle` 2 is gradians**: `SIN(100)` answered 1.
- **Every other plot setting could be set by a program**, and reads 0 but
  for the window, the picture's opacity, 75, and its extent, 0 to 30 by 0
  to 20.

## Deviations

- **Nothing in the interpreter changed.** It implements none of these names
  and not `C→PX`.
- **Whether another app's settings override Home's the same way is still
  open**: a batch cannot select an app.
