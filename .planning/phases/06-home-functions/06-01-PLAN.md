<design>
The guard goes first, in its own task, because it is the cheapest thing to
build and the most expensive to forget. `collect()` builds a row for every
case and hands the same answer to `_report`; a name on `NEVER_STORED` gets a
placeholder in both, so nothing about the machine reaches a committed file or
a session transcript. `SERIAL` is the only name on the list today, and the
list is the point rather than the name.
</design>
