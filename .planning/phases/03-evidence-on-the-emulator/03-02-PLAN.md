<objective>
Run the documentation's examples on the Virtual Calculator in batches, bring
back any kind of answer, keep it with the firmware that gave it, and make the
documentation answer to it.
</objective>

<design>
The harness, one program per batch:

- One row per example in a real matrix (M9 unless it is in use), and a first
  row for the calculator's own `VERSION`.
- A row is: answered (1) or raised (0); `TYPE` of the answer; the answer
  itself when it is a number; the length of `STRING` of the answer; then
  that string as character codes, from `ASC`. Real numbers are also written
  as text, so nothing depends on display settings alone.
- An example with a `;` is a function body and becomes a function of its own;
  an expression is called inline. Every call sits inside `IFERR`.
- The program goes through the linter before it is sent, like compare's.

The run, for the user's decisions:

- The calculator is `DOCS`, cloned from `Prime` once and reset before each
  batch. The program is installed there while no emulator has `DOCS` open.
- Which calculator an emulator opens is the emulator's choice. With `Prime`
  in use, a second emulator opens a free one (measured, deploy.md §1). The
  command launches the emulator, prints the exact keys, waits for that
  process to exit, and confirms from `calc.hpsettings` that it was `DOCS`
  before reading anything. If it was not, it says so and stops.
- `--collect` reads a run that was not waited for.

The results:

- `docs/commands/results.tsv`: entry, call, the answer as the calculator
  displays it (rebuilt from the codes), its type, the firmware string, the
  date. Written by the command, never by hand.
- `hpkit/docs.py`: an example with a stored answer that differs from the
  entry's is a problem ("the emulator answers X on FIRMWARE; the entry says
  Y"); an example labelled `emulator` with no stored answer is a problem.
- `hpprime examples --relabel`: an example labelled `HP help` whose stored
  answer matches becomes `emulator`, linked to results.tsv. It prints every
  change. A `G2` label is never touched.
</design>
